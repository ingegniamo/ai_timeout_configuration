AI Timeout Configuration

Sets the read timeout of AI provider requests with a system parameter.

The Problem

LLMApiService._request in the ai module declares timeout=30, and the Gemini and OpenAI calls do not override it. A slow answer (large prompt, tool calls) ends with a ReadTimeout UserError.

The Fix

The module wraps LLMApiService._request. When the caller passes no timeout, the wrapper reads the system parameter and passes it on. A caller that sets its own timeout (audio transcription uses 550) keeps that value.

Configuration

System parameter Default Meaning
ai.request_timeout120Read timeout in seconds. An empty or non-numeric value falls back to the default.

Set it in Settings > Technical > System Parameters. The value takes effect on the next request, with no restart.
